## What's changed in v1.19.0

### Optional GPU acceleration

- Added optional GPU acceleration with automatic CUDA and MPS detection for AI indexing.
- Added persistent GPU enablement settings and GPU status controls.
- Added consent-gated, on-demand GPU runtime installation with background processing.
- Added restart-required messaging when a newly installed runtime cannot be activated until the next launch.
- AI indexing now falls back to CPU processing when GPU setup is unavailable.

**Full changelog**: https://github.com/baddonkey/exif-turbo/compare/v1.18.1...v1.19.0
