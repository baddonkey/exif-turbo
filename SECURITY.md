# Security Policy

## Supported Versions

Only the current stable minor release line receives security updates. The
project does not maintain long-term-support branches.

| Version | Supported          |
| ------- | ------------------ |
| 1.20.x  | :white_check_mark: |
| < 1.20  | :x:                |
| Pre-release builds | :x:      |

## Reporting a Vulnerability

Please report suspected vulnerabilities through [GitHub's private vulnerability
reporting form](https://github.com/baddonkey/exif-turbo/security/advisories/new).
Private reporting is enabled for this repository. Do not report security issues
in public GitHub Issues, pull requests, or other public channels.

Include the affected exif-turbo version, operating system, affected component,
impact, reproduction steps, and any proof-of-concept needed to verify the issue.
Redact personal paths and identifiers. Do not attach image libraries, database
files, passwords, encryption keys, or other sensitive user data.

We aim to acknowledge a report within five business days and, while investigating
an accepted report, provide an update approximately every 14 calendar days.
These are response targets, not a guarantee of a fix or release date. We will
coordinate remediation and public disclosure with the reporter. If a report is
declined, we will explain the decision privately where practical.

Security reports and fixes do not imply absolute protection. See the project's
[Privacy Scope](README.md#privacy-scope) and the manual's [What the password
protects](docs/user-manual.md#what-the-password-protects) section for the limits
of encryption, local storage, and sensitive data handling.
